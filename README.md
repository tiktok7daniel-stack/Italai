<h1 align="center">Dillo</h1>
<p align="center"><b>قولها بالمصري… واسمعها زي ما الطلاينة بيقولوها.</b></p>

**Dillo** (يعني «قولها!» بالإيطالي) تطبيق ويب (PWA يتثبت على الموبايل) معمول لأي حد عربي عايش في إيطاليا وبيتعلم الإيطالي من الكلام اليومي. الفكرة إنه مش مترجم حرفي: بيديك **الجملة اللي الإيطالي نفسه كان هيقولها** في الموقف ده.

## المميزات

### ✦ قولها
- دوس على المايك واتكلم **بالمصري** (أو اكتب).
- هتاخد:
  - **الجملة زي ما الطلاينة بيقولوها** بالظبط، ومعاها النطق مكتوب بحروف عربي، وتقدر تسمعها بالسرعة العادية أو ببطء.
  - **الترجمة الحرفية الغلط** (اللي محدش بيقولها) وليه هي غلط.
  - **تفكيك الجملة** لحتت، وكل حتة معناها إيه.
  - **طرق تانية** تقولها بيها: مع صحابك، باحترام، باختصار.
  - **القاعدة** اللي في الجملة (الزمن، الضمير…) مشروحة ببساطة.
  - **نصيحة** عن الثقافة الإيطالية لما تكون مفيدة.
- اختار الأسلوب (مع صحابك `tu` / باحترام `Lei`) والموقف (الشغل، كافيه، الدكتور…).
- **وضع «ورّيها»**: الجملة بتظهر كبيرة على الشاشة كلها، تلف التليفون وتوريها للي قدامك أو تشغلها له بالصوت.

### 💬 المحادثة
- التطبيق **بيفضل يسمع** الإيطالي اللي حواليك ويكتبه، وتحت كل جملة معناها بالمصري، والعامية والتعبيرات اللي فيها، واقتراحين ترد بيهم.
- ولما ييجي دورك: اتكلم بالعربي، وهو يقولك تقولها إزاي بالإيطالي، **وهو فاهم سياق الكلام اللي اتقال قبلها**، ويشغلها بالصوت.

### 👆 دوسة طويلة على أي كلمة
أي كلمة إيطالي في التطبيق: دوسة عادية تسمعها، **دوسة طويلة** تفتح شرح كامل:
- المعنى في الجملة دي، وباقي المعاني، والنطق.
- **الكلمة دي جت إزاي** (من أنهي فعل، أنهي زمن، أنهي ضمير، الاختصارات زي `dimmelo` و `nel`).
- **التصريف الكامل** للفعل: presente, passato prossimo, imperfetto, futuro, condizionale, congiuntivo, imperativo، مع تعليم الصيغة اللي اتقالت.
- الفعل المساعد، اسم المفعول، الـ gerundio، المذكر والمؤنث، المفرد والجمع.
- **أصل الكلمة** (لاتيني، وأحياناً عربي!) وكلمات من نفس العيلة وأمثلة من الحياة.

### 📒 كشكولي
احفظ أي جملة أو كلمة، وراجعها بكروت مراجعة (نظام Leitner: اللي بتعرفه يظهر أقل، واللي بتنساه يرجع بسرعة).

## إزاي يشتغل

| الجزء | التقنية |
|---|---|
| الواجهة | React + Vite + TypeScript، تصميم glass غامق، RTL |
| التعرف على الصوت | Web Speech API في المتصفح (`ar-EG` للعربي و `it-IT` للإيطالي) |
| النطق | Speech Synthesis في المتصفح (صوت إيطالي) |
| «المخ» | Claude API (`claude-opus-5-5`) بمخرجات JSON منظمة (structured outputs) |
| السيرفر | Express صغير بيخبي مفتاح الـ API |

> **ليه مش قاعدة بيانات قاموس؟** القواميس المفتوحة (زي Wiktionary) بتدي معنى الكلمة، لكن مش بتعرف «الإيطالي بيقولها إزاي في الموقف ده». النموذج بيفهم المصري العامي والإيطالي المحكي مع بعض، وده لب الفكرة.

## التشغيل

محتاج Node.js 20+ ومفتاح من [Claude Console](https://console.anthropic.com/).

```bash
npm install
export ANTHROPIC_API_KEY=sk-ant-...
npm run dev          # http://localhost:5173
```

للنشر:

```bash
npm run build
ANTHROPIC_API_KEY=sk-ant-... PORT=8787 npm start   # السيرفر بيقدم الواجهة والـ API مع بعض
```

إعدادات اختيارية: `CLAUDE_MODEL` (الافتراضي `claude-opus-5-5`)، `PORT` (الافتراضي `8787`).

**ملاحظات:**
- المايك محتاج **HTTPS** (أو localhost). على الموبايل افتحه من رابط https.
- أحسن متصفح للتعرف على الصوت: **Chrome** على أندرويد والكمبيوتر، أو **Safari** على الآيفون. Firefox مش بيدعمه (تقدر تكتب بدل ما تتكلم).
- من الموبايل: «إضافة للشاشة الرئيسية» وهيشتغل زي التطبيق.
