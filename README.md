<h1 align="center">Dillo</h1>
<p align="center"><b>قولها بالمصري… واسمعها زي ما الطلاينة بيقولوها.</b></p>

**Dillo** (يعني «قولها!» بالإيطالي) تطبيق ويب (PWA يتثبت على الموبايل) معمول لأي حد عربي عايش في إيطاليا وبيتعلم الإيطالي من الكلام اليومي. الفكرة إنه مش مترجم حرفي: بيديك **الجملة اللي الإيطالي نفسه كان هيقولها** في الموقف ده.

## نزّل التطبيق على أندرويد

**رابط مباشر لآخر نسخة:**
https://github.com/tiktok7daniel-stack/Italai/releases/latest/download/Dillo.apk

1. افتح الرابط من الموبايل ونزّل `Dillo.apk`.
2. افتحه، ولو أندرويد طلب «السماح بالتثبيت من المصدر ده» اسمح له.
3. أول مرة هيفتح لك الإعدادات: نزّل **ملفات الترجمة** (العربي والإيطالي، حوالي 30 ميجا لكل واحد، على واي فاي). بعدها الترجمة بتشتغل **من غير نت ومن غير مفتاح**.
   - اختياري: **Gemma** (ذكاء اصطناعي على الموبايل) أو **Claude** (أدق، محتاج مفتاح) من نفس الإعدادات.
4. أول ما تدوس على المايك هيطلب إذن الميكروفون: وافق.

> التعرف على الصوت بيستخدم خدمة جوجل اللي في الموبايل. لو العربي مش بيتعرف عليه: افتح إعدادات جوجل ← الصوت ← اللغات، وضيف **العربية (مصر)** و**الإيطالية**. ولو عايزه يشتغل أحسن من غير نت نزّلهم أوفلاين.

كل مرة الكود يتحدث، GitHub Actions بيبني APK جديد وينزله في [Releases](https://github.com/tiktok7daniel-stack/Italai/releases). النسخة الجديدة بتتثبت فوق القديمة من غير ما الكشكول والإعدادات يضيعوا.

## المميزات

### قولها
- دوس على المايك واتكلم **بالمصري** (أو اكتب).
- هتاخد:
  - **الجملة زي ما الطلاينة بيقولوها** بالظبط، ومعاها النطق مكتوب بحروف عربي، وتقدر تسمعها بالسرعة العادية أو ببطء.
  - **الترجمة الحرفية الغلط** (اللي محدش بيقولها) وليه هي غلط.
  - **تفكيك الجملة** لحتت، وكل حتة معناها إيه.
  - **طرق تانية** تقولها بيها: مع صحابك، باحترام، باختصار.
  - **القاعدة** اللي في الجملة (الزمن، الضمير…) مشروحة ببساطة.
  - **نصيحة** عن الثقافة الإيطالية لما تكون مفيدة.
- اختار الأسلوب (مع صحابك `tu` / باحترام `Lei`) والموقف (الشغل، كافيه، الدكتور…).
- **وضع «ورّيها»**: الجملة بتظهر كبيرة على الشاشة كلها، تلف التليفون وتوريها للي قدامك أو تشغلها له بالصوت.

### المحادثة
- التطبيق **بيفضل يسمع** الإيطالي اللي حواليك ويكتبه، وتحت كل جملة معناها بالمصري، والعامية والتعبيرات اللي فيها، واقتراحين ترد بيهم.
- ولما ييجي دورك: اتكلم بالعربي، وهو يقولك تقولها إزاي بالإيطالي، **وهو فاهم سياق الكلام اللي اتقال قبلها**، ويشغلها بالصوت.

### دوسة طويلة على أي كلمة
أي كلمة إيطالي في التطبيق: دوسة عادية تسمعها، **دوسة طويلة** تفتح شرح كامل:
- المعنى في الجملة دي، وباقي المعاني، والنطق.
- **الكلمة دي جت إزاي** (من أنهي فعل، أنهي زمن، أنهي ضمير، الاختصارات زي `dimmelo` و `nel`).
- **التصريف الكامل** للفعل: presente, passato prossimo, imperfetto, futuro, condizionale, congiuntivo, imperativo، مع تعليم الصيغة اللي اتقالت.
- الفعل المساعد، اسم المفعول، الـ gerundio، المذكر والمؤنث، المفرد والجمع.
- **أصل الكلمة** (لاتيني، وأحياناً عربي!) وكلمات من نفس العيلة وأمثلة من الحياة.

### كشكولي
احفظ أي جملة أو كلمة، وراجعها بكروت مراجعة (نظام Leitner: اللي بتعرفه يظهر أقل، واللي بتنساه يرجع بسرعة).

## الترجمة (الافتراضي): جوجل على الموبايل

- **الترجمة:** Google ML Kit، نفس محرك ترجمة جوجل اللي بيشتغل من غير نت، عربي ⇄ إيطالي.
- **العامية:** الكلام المصري بيتحوّل لفصحى بالقاموس قبل الترجمة، والتطبيق بيوريك «اتفهمت كـ».
- **طريقة الطلاينة:** لو جملتك قريبة من جملة في كتاب الجمل، بتظهر تحت الترجمة.
- **السجل:** كل ترجمة بتتحفظ لوحدها، مقسمة بالأيام، وتقدر تدوّر فيها بالعربي أو الإيطالي.
- **الدوسة على أي كلمة** (من غير ذكاء اصطناعي):
  - المعنى من جوجل (للكلمة وللمصدر بتاعها).
  - التصريف في 14 زمن من [ablaut](https://github.com/ablaut-dev/ablaut)، ودقته 100% في الإيطالي على 280 ألف تصريف.
  - الكلمة جت منين بالقواعد (885 فعل، وأي فعل منتظم يتعرف من آخره).
  - جمل قلتها قبل كده فيها نفس الكلمة.

## المخ اللي على الموبايل (اختياري: Gemma)

- **الموديل:** Gemma 4 من Google (E2B بحجم 2.6 جيجا، أو E4B بحجم 3.7 جيجا للموبايلات القوية)، شغال بـ LiteRT-LM جوه التطبيق على الـ GPU، ولو مينفعش على المعالج.
- **المعرفة اللي متضافة له** (`src/lib/knowledge/`):
  - **كتاب جمل الطلاينة:** جمل يومية مقسمة حسب الموقف، فيها المصري والإيطالي اللي بيتقال فعلاً. لو قلت جملة موجودة فيه، الرد بيطلع على طول من غير الموديل. ولو مش موجودة، أقرب الجمل بتتبعت للموديل كأمثلة على طريقتهم.
  - **قاموس المصري:** كلمات العامية (عايز، دلوقتي، هقدر، لصاحبي…) ومعناها وإيطاليها، بيتبعت للموديل عشان يفهم اللهجة.
- **حاجات من غير ذكاء اصطناعي خالص، ودقتها 100%** (`src/lib/italian/`):
  - **تصريف الأفعال:** بالقواعد، بما فيها الأفعال الشاذة والانعكاسية.
  - **الكلمة جت منين:** مثلاً `sporchi` ← `sporcare` · المضارع · tu.
  - **النطق بالحروف العربي.**
  - عليهم 127 اختبار (`npm test`).

## إزاي يشتغل

| الجزء | التقنية |
|---|---|
| الواجهة | React + Vite + TypeScript، تصميم glass غامق، RTL |
| التعرف على الصوت | Web Speech API في المتصفح (`ar-EG` للعربي و `it-IT` للإيطالي) |
| النطق | Speech Synthesis في المتصفح (صوت إيطالي) |
| «المخ» | Gemma 4 على الموبايل (LiteRT-LM)، أو Claude API (`claude-opus-5-5`) اختياري |
| تطبيق أندرويد | Capacitor (التعرف على الصوت والنطق من نظام أندرويد نفسه) |
| السيرفر (للويب بس) | Express صغير بيخبي مفتاح الـ API |

> **ليه مش قاعدة بيانات قاموس؟** القواميس المفتوحة (زي Wiktionary) بتدي معنى الكلمة، لكن مش بتعرف «الإيطالي بيقولها إزاي في الموقف ده». النموذج بيفهم المصري العامي والإيطالي المحكي مع بعض، وده لب الفكرة.

## التشغيل على الكمبيوتر (للتطوير)

محتاج Node.js 20+ ومفتاح من [Claude Console](https://console.anthropic.com/).

```bash
npm install
export ANTHROPIC_API_KEY=sk-ant-...
npm run dev          # http://localhost:5173
```

للنشر:

```bash
npm run build
ANTHROPIC_API_KEY=sk-ant-... PORT=8787 npm start   # السيرفر بيقدم الواجهة والـ API مع بعض
```

إعدادات اختيارية: `CLAUDE_MODEL` (الافتراضي `claude-opus-5-5`)، `PORT` (الافتراضي `8787`).

**ملاحظات:**
- المايك محتاج **HTTPS** (أو localhost). على الموبايل افتحه من رابط https.
- أحسن متصفح للتعرف على الصوت: **Chrome** على أندرويد والكمبيوتر، أو **Safari** على الآيفون. Firefox مش بيدعمه (تقدر تكتب بدل ما تتكلم).
- من الموبايل: «إضافة للشاشة الرئيسية» وهيشتغل زي التطبيق.

### بناء الـ APK بنفسك

محتاج Android SDK و Java 21:

```bash
npm run build && npx cap sync android
cd android && ./gradlew assembleRelease
# الملف: android/app/build/outputs/apk/release/app-release.apk
```

**التوقيع:** النسخ بتتوقع بمفتاح debug موجود في `android/app/dillo-debug.keystore` (عشان التحديثات تتثبت فوق بعض). الريبو ده public، فلو عايز مفتاح خاص بيك: اعمل keystore وضيفه في GitHub Secrets باسم `DILLO_KEYSTORE_BASE64` (الملف base64) و`DILLO_KEYSTORE_PASSWORD` و`DILLO_KEY_ALIAS` و`DILLO_KEY_PASSWORD`. ولما تغيّر المفتاح هتحتاج تمسح النسخة القديمة مرة واحدة وتثبت الجديدة.
